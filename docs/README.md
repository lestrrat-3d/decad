# decad user documentation

This directory holds documentation for people who use decad as a library.

- [API reference](api.md) names every public function by task and links to the Go doc comments.
- [Data structures](data-structures.md) indexes every exported type and explains the model, topology, geometry,
  measurement and report structures.
- [`images/`](images/) holds the pictures and clips that the top-level README shows.
- The [top-level README](../README.md) introduces the library.
- [`examples/`](../examples) holds executable Go examples with verified output.

Design decisions and maintenance instructions live in [`agent-docs/`](../agent-docs/README.md).
