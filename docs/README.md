# decad user documentation

This directory holds documentation for people who use decad as a library.

- [Public API design](api-design.md) is the canonical API reference. It covers units, coordinates, the document and
  bodies, features, selectors, verification, export and errors.
- [`images/`](images/) holds the pictures and clips that the top-level README shows.
- The [top-level README](../README.md) introduces the library and links runnable examples.
- [`examples/`](../examples) holds executable Go examples with verified output.

Documentation for people and agents who develop, fix or maintain decad lives in [`agent-docs/`](../agent-docs/README.md).
